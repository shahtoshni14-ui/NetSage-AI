PROJECT

What NetSage AI does

NetSage reads symptoms and Cisco-style show-command evidence, identifies a probable fault, highlights evidence, recommends the next diagnostic command and presents a safe remediation path.

This GitHub Pages build is a static interactive demo. It intentionally does not expose an API key. The full Flask/Gemini application remains in the repository.
